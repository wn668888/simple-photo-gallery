图库还是空的

  1. 把图片放进 photos/bags（包包）、photos/scarves（围巾）、photos/watches（手表）
  2. 执行 npm run normalize:apply，把中文 / 空格文件名改成英文
  3. 执行 npm run build 生成索引，刷新本页即可看到

部署到 Vercel 后，上面第 2、3 步由平台自动完成，你只需要上传图片。
